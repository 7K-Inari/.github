# 7K-Inari organization defaults

This repository contains the [public organization profile](profile/README.md) and default community health files for the 7K-Inari organization.

GitHub inherits these defaults into repositories that do not provide their own corresponding file. Repository-specific policies remain authoritative where present; do not copy these defaults into repositories that already have them.

Canonical project policies, CLA texts, and approval status are maintained in [inari-docs](https://github.com/7K-Inari/inari-docs).

Brand assets in `profile/assets` come from [7K-Group/7k-design-system](https://github.com/7K-Group/7k-design-system); see the asset notice for provenance and licensing.
